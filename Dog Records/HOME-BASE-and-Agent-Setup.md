## A) The three agents — how to use them

**Way 1 (fastest, nothing to set up):** ask Claude in chat and name the agent —
*"As the Taco Medical Agent: Taco is straining to pee again — what should I ask the vet?"*

**Way 2 (permanent, on your claude.ai home screen): make a Claude Project per dog:**
1. claude.ai → **Projects** → **+ Create project**
2. Name it (below) · 3. Paste the instruction block into **custom instructions** ·
4. Add the dog's Drive doc (or the whole `Dog Records` folder) to **Knowledge** · 5. Click in and ask.
